# AutoPrime RD

Proyecto React + TypeScript + Vite con página individual para cada vehículo.

## Ejecutar

```bash
npm install
npm run dev
```

## Página de detalles

Cada botón **Ver detalle** abre una ruta como:

```text
/vehiculos/toyota-corolla-2021
```

Los vehículos y sus datos se administran desde:

```text
src/data/vehicles.ts
```

## WhatsApp

En `src/pages/VehicleDetails.tsx`, reemplaza `18090000000` por el número real de la agencia, incluyendo el código de país y sin espacios.
